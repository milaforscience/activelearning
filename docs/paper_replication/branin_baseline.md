# Branin Replication Status

The canonical Branin benchmark page is now
[Branin Benchmark](../examples/branin_toy.md).

Use that page for:

- the current runnable baseline: `config/branin_multi_fidelity.yaml`,
- the adaptable scaffolds: `config/branin_toy.yaml` and
  `config/branin_gflownet_toy.yaml`, and
- the current boundary between benchmark use and future paper-replication work.

Replication caveat: the Branin baseline is runnable, but the repository does
not yet include the full set of paper comparison configurations or a complete
end-to-end multi-fidelity GFlowNet path.
