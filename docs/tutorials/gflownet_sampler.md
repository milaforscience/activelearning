# GFlowNet Sampler Setup

!!! warning "Not yet implemented"
    GFlowNet sampler support is planned as a future extension. This page is a placeholder and will be updated when the integration is available.

The GFlowNet sampler will train a generative flow network as a proposal mechanism, guided by the current acquisition function as a reward signal. Candidates will be sampled proportional to the acquisition signal, promoting diversity over greedy exploitation.
