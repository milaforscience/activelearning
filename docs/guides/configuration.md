# Configuration Guide

Configuration guidance is consolidated in [Runtime and Configuration](../concepts/runtime_and_configuration.md), the canonical reference for run schema, runtime propagation, multi-fidelity settings, and CLI overrides.

For baseline configurations, start from `config/branin_multi_fidelity.yaml` or `config/branin_gflownet_toy.yaml`. See [Config Examples](../examples/configs.md) for curated examples.
